## Overview

A cutting-edge personal portfolio showcasing **Agentic AI systems**, **Model Context Protocol (MCP)** servers, **RAG document retrieval pipelines**, and **AI-driven security automation**. Built with a 3D WebGL space particle system in Three.js and GSAP motion design.

---

## Featured AI Projects

- **Hexstrike AI — MCP Pentesting Server**: AI-orchestrated pentesting server exposing 150+ security tools through the Model Context Protocol (MCP), enabling LLM agents to plan, execute, and chain security workflows over stdio transport with Claude Desktop and VS Code.
- **ScreenAI — LLM Screen Agent**: Live Android screen overlay routing context to Gemini 1.5 Flash via REST API with sub-1.8s response latency and structured prompt engineering.
- **RAG Document Q&A Pipeline**: High-performance retrieval-augmented generation over multi-page technical documents using FAISS vector stores & HuggingFace sentence-transformers.
- **Real-Time AI Voice Calling Agent**: Conversational voice agent architecture integrating Twilio telephony streams with WebSockets and LLM endpoints.
- **Gesture PC Control & Anomaly Detection**: Computer vision control interface achieving 94% accuracy with OpenCV, MediaPipe, SHA-256 gated execution, and lightweight EDR logging.
- **MetaClean Privacy Scrubber**: Installable client-side EXIF/GPS metadata scrubber PWA.
